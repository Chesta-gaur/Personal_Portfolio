# 🚀 Personal Portfolio Website

A modern, responsive, and fully animated developer portfolio built using **React.js**.
This project showcases my skills, projects, and experience with a clean UI and smooth user interactions.

## 📌 Features

* ⚡ Modern UI with glassmorphism design
* 🎯 Fully responsive across devices
* 🎬 Scroll-based animations using AOS
* 💻 Dynamic project showcase section
* 📊 Animated skills progress bars
* 🧠 Interactive About & Education timeline
* 📩 Functional contact form UI
* 🔗 Social media integration
* 📄 Resume download option

---

## 🛠️ Tech Stack

**Frontend:**

* React.js
* JavaScript (ES6+)
* HTML5, CSS3
* Bootstrap

**Libraries & Tools:**

* AOS (Animate On Scroll)
* React Icons
* React Typed
