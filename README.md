# React Developer Portfolio

A modern personal portfolio website built with **React** and **Bootstrap** to showcase my projects, technical skills, and development experience.

---

## Features

- Responsive modern UI
- Single page navigation
- Reusable React components
- Bootstrap layout and utilities
- Smooth navigation between sections
- Sections for About, Skills, Education, Projects, and Contact

---

## Tech Stack

- React
- JavaScript (ES6+)
- Bootstrap
- CSS3
- HTML5

---

## Project Structure

src/
components/ → Reusable UI components  
pages/ → Page sections (Home, About, etc.)  
styles/ → Component styling  
assets/ → Images and media  
data/ → Static data used in the UI
